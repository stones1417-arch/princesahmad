# 🕌 منصة أبواب (Abwab Platform)

منصة أبواب هي نظام إلكتروني متكامل لإدارة وتشغيل أبواب المسجد الحرام، تم تطويره باستخدام Django لتسهيل إدارة المناوبات، توزيع الموظفين، متابعة حالة الأبواب، التقارير التشغيلية، والإدارة المركزية.

---

# 📋 نبذة عن المشروع

تهدف منصة أبواب إلى رقمنة جميع العمليات التشغيلية المتعلقة بالأبواب، من خلال نظام موحد يوفر:

- إدارة الموظفين
- إدارة الورديات
- توزيع الموظفين على الأبواب
- متابعة حالة الأبواب
- تسجيل البلاغات والصيانة
- التقارير التشغيلية
- الإعلانات الداخلية
- الإشعارات
- مركز التصدير
- لوحة تحكم متكاملة

# 🚀 تثبيت المشروع

## استنساخ المشروع

```bash
git clone https://github.com/stones1417-arch/princesahmad.git
```

ثم

```bash
cd princesahmad
```

---

## إنشاء البيئة الافتراضية

Windows

```bash
python -m venv venv
```

تفعيل البيئة

```bash
venv\Scripts\activate
```

---

## تثبيت المتطلبات

```bash
pip install -r requirements.txt
```

---

## تنفيذ الهجرات

```bash
python manage.py migrate
```

---

## إنشاء مستخدم مدير

```bash
python manage.py createsuperuser
```

---

## تشغيل المشروع

```bash
python manage.py runserver
```

ثم افتح

```
http://127.0.0.1:8000
```
